# 🍽️ Odin Recipes

## 📌 About the Project

Odin Recipes is a simple recipe website created using HTML as part of **The Odin Project – Foundations Course**.

The website contains three delicious Indian recipes with images, descriptions, ingredients, and step-by-step cooking instructions.

The main goal of this project is to practice basic HTML concepts and understand how to create and link multiple web pages.

## 🍛 Recipes Included

1. **Paneer Butter Masala** – A popular Indian curry made with paneer, butter, and spices.
2. **Chole** – A delicious North Indian chickpea curry.
3. **Masala Dosa** – A crispy South Indian dish served with potato filling.

## 🛠️ Technologies Used

- HTML5
- Git
- GitHub
- Visual Studio Code

## ✨ Features

- Simple and easy-to-navigate website
- Three different Indian recipes
- Food images and descriptions
- Ingredients displayed using unordered lists
- Cooking instructions displayed using ordered lists
- Navigation between the homepage and recipe pages

## 📚 What I Learned

Through this project, I practiced:

- Creating basic HTML page structures
- Using headings, paragraphs, and images
- Working with ordered and unordered lists
- Linking multiple HTML pages using anchor tags
- Understanding relative file paths
- Organizing project files and folders
- Using Git and GitHub for version control
